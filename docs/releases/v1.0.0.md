# Piste 1.0.0

Première version Android installable de Piste, un carnet de suivi des candidatures.

## Fonctionnalités

- Création, consultation et modification d’une candidature avec entreprise,
  poste, statut, relance facultative, notes et lien d’offre.
- Validation des champs obligatoires et confirmation avant suppression.
- Conservation des candidatures dans une base SQLite locale après redémarrage.
- Recherche et filtres par statut, accueil synthétique et bilan global.
- Interface française inspirée du kit Figma Piste 2026, avec police Inter intégrée.

## Installation

Télécharger `piste-1.0.0-android.apk`, puis l’ouvrir sur Android. Si le système
le demande, autoriser l’installation depuis l’application qui ouvre le fichier.
Android 7.0 ou plus récent est requis. Une nouvelle installation démarre sans candidature.

L’identifiant de diffusion est `io.github.getill.piste`. Cette version s’installe
à côté de l’ancienne application de développement des TP ; elle ne reprend pas
sa base de données.

## Pièces jointes

- `piste-1.0.0-android.apk` : APK release signé avec la clé de diffusion de Piste.
- `SHA256SUMS.txt` : empreinte permettant de vérifier le téléchargement.
- Trois captures authentiques de la version release : accueil, fiche et bilan.

## Validation

Analyse sans erreur, 24 tests automatisés réussis. L’APK signée a été installée
sur un émulateur Android 16 : validation du formulaire, création, modification
de relance, suppression annulée puis confirmée et persistance vérifiée après
arrêts complets. La signature a été contrôlée avec `apksigner`.

## Limites de la V1

Données locales, sans compte ni synchronisation entre appareils. Le profil,
les notifications et le thème sombre ne sont pas implémentés. Le stockage Web
et Linux n’est pas configuré. La livraison est Android ; aucune IPA iOS n’est fournie.

[Instructions et scénario de démonstration](https://github.com/getill/piste/blob/v1.0.0/docs/livraison.md)

# Données de Piste 1.0.0

Piste enregistre les candidatures dans la base SQLite privée de l’application,
sur l’appareil Android : entreprise, poste, statut, notes, lien d’offre et dates.

L’application ne possède ni compte utilisateur, ni serveur, ni outil de publicité
ou d’analyse d’usage. Le lien d’offre est affiché comme texte consultable ; aucun
appel réseau n’est nécessaire pour gérer les candidatures.

L’utilisateur peut modifier ou supprimer chaque candidature depuis sa fiche.
Les éventuelles sauvegardes réalisées par le système Android dépendent de ses
réglages. Désinstaller l’application supprime sa base locale sur l’appareil ;
cette V1 ne propose pas de fonction d’export ou de restauration.

Projet : [getill/piste](https://github.com/getill/piste).
